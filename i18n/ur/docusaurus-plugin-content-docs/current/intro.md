# فزیکل ای آئی اور ہیومنوائڈ روبوٹکس کا تعارف

## روبوٹکس کی تعلیم کے مستقبل میں خوش آمدید

یہ نصاب فزیکل ای آئی اور ہیومنوائڈ روبوٹکس کا جامع تعارف فراہم کرتا ہے، ڈیجیٹل انٹیلی جنس اور امبدڈ ایجنٹس کے درمیان پُل بناتا ہے۔ آپ جانیں گے کہ مصنوعی ذہانت کو جسمانی نظاموں میں کیسے امبد کیا جا سکتا ہے تاکہ وہ حقیقی دنیا کے ساتھ تعامل کر سکیں۔

## آپ کیا سیکھیں گے

اس نصاب میں، آپ:

- فزیکل ای آئی اور امبدڈ انٹیلی جنس کے بنیادی تصورات کو سمجھیں گے
- سیکھیں گے کہ روبوٹکس سسٹم کے لیے ای آئی کی تکنیکیں کیسے لاگو کی جاتی ہیں
- ROS2، گیزبو، اور آئزک سِم کے ساتھ ہینڈز آن تجربہ حاصل کریں گے
- انسان-روبوٹ تعامل کے اصولوں کو سمجھیں گے
- روبوٹ کنٹرول اور نیویگیشن میں مہارت حاصل کریں گے
- مکمل روبوٹکس سسٹم کو امبد اور ڈپلائی کرنا سیکھیں گے

## لازمی شرائط

اس نصاب کا آغاز کرنے سے پہلے، آپ کے پاس ہونا چاہیے:

- بنیادی پروگرامنگ کا علم (ترجیحی طور پر پائی تھن)
- بنیادی ریاضی کی سمجھ (لکیری الجبرا، حسابان)
- بنیادی روبوٹکس کے تصورات سے واقفیت (اختیاری لیکن مددگار)

## اس نصاب کو کیسے استعمال کریں

یہ نصاب 6 ماڈیولز میں منظم ہے، ہر ایک پچھلے ماڈیول کی بنیاد پر تعمیر ہوتا ہے۔ ہر ماڈیول میں ہے:

- نظریاتی وضاحتیں ڈائریم کے ساتھ
- عملی کوڈ کی مثالیں
- ROS2، گیزبو، اور آئزک سِم کا استعمال کرتے ہوئے ہینڈز آن لیبز
- آپ کی سیکھ کو مضبوط کرنے کے لیے مشقیں

## ٹیکنالوجی اسٹیک

پورے اس نصاب کے دوران، ہم استعمال کریں گے:

- **ROS2**: روبوٹ سافٹ ویئر ڈویلپمنٹ کے لیے روبوٹ آپریٹنگ سسٹم
- **گیزبو**: روبوٹ سیمولیشن ماحول
- **آئزک سِم**: NVIDIA کا روبوٹکس سیمولیشن پلیٹ فارم
- **پائی تھن**: روبوٹکس ایپلی کیشنز کے لیے بنیادی پروگرامنگ زبان
- **ڈاکر**: مسلسل ترقی کے ماحول کے لیے

## شروع کریں

اچھی تعلیم کے تجربے کے لیے، فزیکل ای آئی کے تصورات میں مضبوط بنیاد قائم کرنے کے لیے ماڈیول 1 سے شروع کریں، پھر ہر ماڈیول کو ترتیب وار آگے بڑھیں۔ ہر ماڈیول میں نظریاتی تصورات پر مبنی ہینڈز آن لیبز ہیں۔

## لیب پیش نظارہ: پہلا روبوٹ سیمولیشن

ماڈیول 2 میں، آپ گیزبو کا استعمال کرتے ہوئے اپنا پہلا روبوٹ سیمولیشن چلائیں گے:

```python
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import Twist

class SimpleController(Node):
    def __init__(self):
        super().__init__('simple_controller')
        self.publisher = self.create_publisher(Twist, '/cmd_vel', 10)
        self.timer = self.create_timer(0.1, self.timer_callback)

    def timer_callback(self):
        msg = Twist()
        msg.linear.x = 1.0  # آگے بڑھیں
        msg.angular.z = 0.5  # ذرا سا مڑیں
        self.publisher.publish(msg)

def main(args=None):
    rclpy.init(args=args)
    controller = SimpleController()
    rclpy.spin(controller)
    controller.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```

یہ سادہ کنٹرولر سیمولیشن میں ایک روبوٹ کو حرکت دے گا، کوڈ اور جسمانی رویے کے درمیان رابطہ کو ظاہر کرتا ہے۔
