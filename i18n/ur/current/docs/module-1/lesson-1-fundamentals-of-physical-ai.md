# جسمانی مصنوعی ذہانت کے بنیادیات

## جسمانی مصنوعی ذہانت کیا ہے؟

جسمانی مصنوعی ذہانت روایتی ڈیجیٹل مصنوعی ذہانت سے ایک نمونہ تبدیلی کی نمائندگی کرتی ہے تاکہ ایسے مصنوعی ذہانت کے نظاموں کو تیار کیا جا سکے جو جسمانی دنیا کے ساتھ بات چیت کر سکیں۔ کلاسیکی مصنوعی ذہانت کے برعکس جو معلومات کو مطلق ڈیجیٹل خلا میں عمل کرتی ہے، جسمانی مصنوعی ذہانت میں ذہانت کو جسمانی اظہار کے ساتھ ضم کیا جاتا ہے، ایسے نظام تیار کرتا ہے جو حقیقی دنیا کے ماحول میں ادراک، سوچ بچار اور عمل کر سکتے ہیں۔

### جسمانی مصنوعی ذہانت کی کلیدی خصوصیات

1. **جسمانی اظہار**: ذہانت جسمانی شکل میں جڑی ہوتی ہے
2. **بین الاقوامی بات چیت**: ماحول کے ساتھ مسلسل بات چیت
3. **سینسریموٹر انضمام**: ادراک اور عمل کے درمیان تنگ تعلق
4. **حقوقی وقت کی پروسیسنگ**: ماحولیاتی تبدیلیوں کا حقیقی وقت میں جواب
5. **جسمانی پابندیاں**: جسمانی قوانین اور پابندیوں کے اندر کام کرنا

## اظہار کا اصول

اظہار کا اصول کہتا ہے کہ ایک ذہین نظام کی جسمانی شکل اس کی کلیہ صلاحیات پر نمایاں اثر ڈالتی ہے۔ اس کا مطلب یہ ہے:

- ایک روبوٹ کی شکل اور ساخت اس بات کو متاثر کرتی ہے کہ وہ دنیا کو کیسے محسوس کرتا ہے
- جسمانی بات چیت اس طرح کے سیکھنے کے مواقع فراہم کرتی ہے جو سیمولیشن میں دستیاب نہیں ہیں
- جسمانیات کے ذریعہ عائد کردہ پابندیاں سیکھنے اور مطابقت کی رہنمائی کرتی ہیں

```python
# مثال: اظہار کیسے ادراک کو متاثر کرتا ہے
class EmbodiedPerception:
    def __init__(self, sensor_config, body_dimensions):
        self.sensors = sensor_config
        self.dimensions = body_dimensions
        self.embodied_knowledge = {}

    def perceive_environment(self, sensory_input):
        # جسمانی پابندیاں اس بات کو متاثر کرتی ہیں کہ معلومات کو کیسے عمل کیا جاتا ہے
        processed_data = self.apply_embodiment_constraints(sensory_input)
        return self.integrate_sensory_data(processed_data)

    def apply_embodiment_constraints(self, data):
        # جسمانی شکل کی بنیاد پر علم کا اطلاق کریں
        constrained_data = {
            'reachable_area': self.calculate_reachability(),
            'view_cone': self.calculate_field_of_view(),
            'physical_interactions': self.calculate_collision_space()
        }
        return {**data, **constrained_data}
```

## جسمانی مصنوعی ذہانت بمقابلہ روایتی مصنوعی ذہانت

| روایتی مصنوعی ذہانت | جسمانی مصنوعی ذہانت |
|----------------------|----------------------|
| ڈیجیٹل ماحول میں کام کرتا ہے | جسمانی ماحول میں کام کرتا ہے |
| معلومات کی پروسیسنگ پر توجہ | جسمانی بات چیت پر توجہ |
| مطلق مسئلہ حل کرنا | سیاقی مسئلہ حل کرنا |
| سٹیٹک علم کا ذخیرہ | بات چیت کے ذریعہ مسلسل سیکھنا |
| محدود فیڈ بیک لوپ | غنی سینسریموٹر فیڈ بیک |

## جسمانی مصنوعی ذہانت کے اطلاقات

جسمانی مصنوعی ذہانت متعدد شعبوں میں انقلاب لا رہی ہے:

### صحت کی دیکھ بھال کی روبوٹکس
- بزرگ دیکھ بھال کے لیے معاون روبوٹس
- ہیپٹک فیڈ بیک کے ساتھ سرجری روبوٹس
- جسمانی علاج کے لیے دواؤں کے روبوٹس

### صنعتی خودکاری
- موافق مینوفیکچرنگ سسٹم
- انسانوں کے ساتھ کام کرنے والے ملک میٹ روبوٹس (کوبوٹس)
- سیکھنے کی صلاحیتوں کے ساتھ معیار کی تحقیق روبوٹس

### سروس روبوٹکس
- خودکار ترسیل روبوٹس
- کسٹمر سروس روبوٹس
- گھریلو کاموں کے لیے گھریلو روبوٹس

### تحقیق اور تلاش
- سیاروں کی تلاش کے روبوٹس
- پانی کے نیچے کے تلاش سسٹم
- آفت کے جواب کے روبوٹس

## ادراک-عمل کا چکر

جسمانی مصنوعی ذہانت کے نظام مسلسل ادراک-عمل کے چکروں کے ذریعہ کام کرتے ہیں:

```
ماحول → سینسر → ادراک → منصوبہ بندی → عمل → ایفیکٹرز → ماحول
     ↑______________________________________________________________|
```

یہ چکر اس کے قابل بناتا ہے:

- ماحولیاتی تبدیلیوں کے لیے حقیقی وقت میں مطابقت
- بات چیت کے ذریعہ سیکھنا
- سادہ اصولوں سے نمودار ہونے والے رویے
- فیڈ بیک کے ذریعہ مضبوطی

## ریاضی کی بنیاد

جسمانی مصنوعی ذہانت کے نظاموں کو ریاستی خلا کے نمائندگیوں کا استعمال کرتے ہوئے ماڈل کیا جا سکتا ہے:

```
x(t+1) = f(x(t), u(t), w(t))  # ریاست کی منتقلی
y(t) = h(x(t), v(t))          # مشاہدہ ماڈل
```

جہاں:
- x(t) وقت t پر نظام کی حالت ہے
- u(t) کنٹرول ان پٹ ہے
- y(t) مشاہدہ ہے
- w(t) اور v(t) عمل اور مشاہدہ کی آوازیں ہیں

## لیب: اظہار کے اثرات کی تلاش

اس لیب میں، ہم اظہار کے مختلف روبوٹ کے ادراک اور نیویگیشن پر اثرات کو سمجھنے کے لیے گیزبو کا استعمال کریں گے:

```python
#!/usr/bin/env python3
# lab_embodiment_effects.py

import rclpy
from rclpy.node import Node
from sensor_msgs.msg import LaserScan
from geometry_msgs.msg import Twist
import numpy as np

class EmbodimentLab(Node):
    def __init__(self):
        super().__init__('embodiment_lab')

        # لیزر اسکین ڈیٹا کو سبسکرائب کریں
        self.scan_sub = self.create_subscription(
            LaserScan,
            '/scan',
            self.scan_callback,
            10
        )

        # روبوٹ کی حرکت کے لیے پبلشر
        self.cmd_vel_pub = self.create_publisher(Twist, '/cmd_vel', 10)

        self.scan_data = None

    def scan_callback(self, msg):
        self.scan_data = msg.ranges

        # حساب لگائیں کہ اظہار ادراک کو کیسے متاثر کرتا ہے
        # (روبوٹ کی جسمانی ابعاد سینسر کوریج کو متاثر کرتی ہیں)
        effective_range = self.calculate_effective_perception_range()
        self.get_logger().info(f'Effective perception range: {effective_range:.2f}m')

        # اظہار-آگاہ ادراک کی بنیاد پر سادہ نیویگیشن
        self.navigate_awarely()

    def calculate_effective_perception_range(self):
        # ادراک میں روبوٹ کی جسمانی ابعاد کا خیال رکھیں
        # مثال کے طور پر، ایک چوڑا روبوٹ کے مختلف اندھیرے کے مقامات ہیں
        robot_width = 0.5  # میٹر
        sensor_mount_height = 0.3  # میٹر

        # جسمانی پابندیوں کی بنیاد پر مؤثر حد کا حساب لگائیں
        min_range = min([r for r in self.scan_data if r > 0]) if self.scan_data else 0
        effective_range = min_range - (robot_width / 2)  # روبوٹ کی چوڑائی کا احتساب

        return max(0, effective_range)

    def navigate_awarely(self):
        if not self.scan_data:
            return

        # سادہ نیویگیشن جو اظہار کا خیال رکھتی ہے
        msg = Twist()

        # راستے میں رکاوٹوں کی جانچ کریں (روبوٹ کی چوڑائی کا خیال رکھتے ہوئے)
        front_clear = all(d > 1.0 for d in self.scan_data[300:600] if d > 0)  # سامنے 60 ڈگری

        if front_clear:
            msg.linear.x = 0.5  # آگے بڑھیں
            msg.angular.z = 0.0
        else:
            msg.linear.x = 0.0
            msg.angular.z = 0.5  # دائیں مڑیں

        self.cmd_vel_pub.publish(msg)

def main(args=None):
    rclpy.init(args=args)
    lab_node = EmbodimentLab()

    try:
        rclpy.spin(lab_node)
    except KeyboardInterrupt:
        pass
    finally:
        lab_node.destroy_node()
        rclpy.shutdown()

if __name__ == '__main__':
    main()
```
