# جسمانی مصنوعی ذہانت اور انسان نما روبوٹکس کا تعارف

## روبوٹکس کی تعلیم کے مستقبل میں خوش آمدید

یہ کتاب جسمانی مصنوعی ذہانت اور انسان نما روبوٹکس کا جامع تعارف فراہم کرتی ہے، جو ڈیجیٹل ذہانت اور جسمانی ایجنٹس کے درمیان پُل کا کام کرتی ہے۔ آپ جانیں گے کہ مصنوعی ذہانت کو جسمانی نظاموں میں کیسے بروئے کار لایا جا سکتا ہے تاکہ حقیقی دنیا کے ساتھ بات چیت کرنے والے روبوٹس تیار کیے جا سکیں۔

## آپ کیا سیکھیں گے

اس کتاب میں، آپ:

- جسمانی مصنوعی ذہانت اور جسمانی ذہانت کے بنیادی تصورات سمجھیں گے
- روبوٹکس سسٹم کے لیے مصنوعی ذہانت کی تکنیکوں کو نافذ کرنا سیکھیں گے
- ROS2، Gazebo، اور Isaac Sim کے ساتھ عملی تجربہ حاصل کریں گے
- انسان-روبوٹ بات چیت کے اصولوں کو سمجھیں گے
- روبوٹ کنٹرول اور نیویگیشن میں مہارت حاصل کریں گے
- مکمل روبوٹکس سسٹم کو ضم کرنے اور نافذ کرنا سیکھیں گے

## ضروریات

اس کتاب کو شروع کرنے سے پہلے، آپ کے پاس ہونا چاہیے:

- بنیادی پروگرامنگ کا علم (Python کو ترجیح دی جاتی ہے)
- بنیادی ریاضی کی سمجھ (لکیری الجبرا، کیلکولس)
- بنیادی روبوٹکس کے تصورات سے واقفیت (اختیاری لیکن مددگار)

اس کتاب بھر میں، ہم استعمال کریں گے:

## لیب پیش نظارہ: پہلا روبوٹ سیمولیشن

ماڈیول 2 میں، آپ Gazebo کا استعمال کرتے ہوئے اپنا پہلا روبوٹ سیمولیشن چلائیں گے:

```python
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import Twist

class SimpleController(Node):
    def __init__(self):
        super().__init__('simple_controller')
        self.publisher = self.create_publisher(Twist, '/cmd_vel', 10)
        self.timer = self.create_timer(0.1, self.timer_callback)

    def timer_callback(self):
        msg = Twist()
        msg.linear.x = 1.0  # آگے بڑھیں
        msg.angular.z = 0.5  # تھوڑا سا مڑیں
        self.publisher.publish(msg)

def main(args=None):
    rclpy.init(args=args)
    controller = SimpleController()
    rclpy.spin(controller)
    controller.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```

یہ سادہ کنٹرولر سیمولیشن میں ایک روبوٹ کو حرکت میں لائے گا، جو کوڈ اور جسمانی رویے کے درمیان رابطے کو ظاہر کرتا ہے۔
